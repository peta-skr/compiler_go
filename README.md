# compiler_go

Thorsten Ballの『Writing A Compiler In Go』に沿って、Monkey言語のバイトコードコンパイラと仮想マシン（VM）をGoで書き始めた、1回目の取り組み。第7章（関数）の途中で止めており、同じ本は [monkey_compiler](https://github.com/peta-skr/monkey_compiler) で最初からやり直して最終章まで書き終えた。

ここで書いたのは `code/`（オペコード24種類の定義とエンコード）、`compiler/`、`vm/` で、整数・真偽値・文字列・配列・ハッシュの式、条件分岐、グローバル変数のコンパイルと実行、関数呼び出しの書きかけまでが入っている。字句解析器・構文解析器・評価器（`lexer/` `parser/` `evaluator/` など）は、前作『Go言語でつくるインタプリタ』の完成時点のコードを最初のコミットで取り込んだもの。

## 動かし方

今の状態では `go build ./...` が通らない。VMを呼び出しフレーム方式に書き換えている途中で、`vm/vm.go` に古いフィールド `vm.instructions` を参照する箇所が残っているため。前作から取り込んだ部分のテストは通る。

```sh
go test ./lexer/... ./parser/... ./ast/... ./evaluator/... ./object/...
```

## 使った技術

- Go（`go.mod` の指定は `go 1.21.5`）。外部パッケージは使っていない
- 1バイトのオペコードとビッグエンディアンのオペランドによる命令列、スタック型VM

## 学んだこと

- 命令をバイト列にエンコードし、逆アセンブルして読める形に戻す方法
- 式と条件分岐をスタック型VMの命令に変換して実行する流れ
